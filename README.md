# Automated AWS Infrastructure & Application Deployment Platform

An automation platform built with Ansible and AWS to provision infrastructure, configure servers, deploy containerized applications, and validate deployments.

## Tech Stack

- AWS EC2
- Ansible
- Ansible Vault
- Docker
- Git
- GitHub
- GitHub Actions

## Project Goals

- Automate AWS infrastructure provisioning
- Automate server configuration
- Securely manage secrets
- Automate Docker installation and application deployment
- Implement health checks and validation
- Build repeatable and idempotent automation
- Add CI validation using GitHub Actions
